## Project Overview

This ArcGIS Pro portfolio project demonstrates a complete survey-style GIS workflow using simulated field observations in the Murray State University area of Murray, Kentucky.

The project was developed to strengthen practical GIS skills in:

- Survey-style feature mapping
- GPS observations
- Survey control points
- Point, line, and polygon feature creation
- File geodatabase organization
- Attribute management
- Spatial and distance analysis
- Coordinate systems
- Feature labeling
- Symbology
- Parcel and site mapping
- Professional cartographic layout design

Three final maps were produced to demonstrate different stages of the GIS surveying workflow.

> **Important Note:**  
> The GPS observations, survey control points, parcel features, and field observations used in this project are simulated training data created for GIS skill development and portfolio demonstration. They should not be interpreted as professional land-survey measurements or legally authoritative cadastral data.

---

# Project Objectives

The primary objectives of this project were to:

- Create and manage point, line, and polygon feature classes.
- Build an organized ArcGIS Pro file geodatabase.
- Create simulated survey and GPS observation datasets.
- Design useful attribute fields and unique feature IDs.
- Create and visualize survey control points.
- Digitize buildings, parking areas, landscaped areas, drainage features, roads, fences, and site boundaries.
- Work with geographic and projected coordinate systems.
- Perform basic spatial and distance analysis.
- Apply meaningful symbology and labeling.
- Produce professional map layouts suitable for a GIS portfolio.

# GIS Data Types

The project uses the three fundamental GIS geometry types.

## Point Features

Point features represented individual field or survey locations, including:

- Building Corners
- Drainage Inlets
- Signs
- Survey Control Points
- Trees
- Utility Poles
- GPS Observation Points

## Line Features

Line features represented linear infrastructure or survey features, including:

- Access Roads
- Drainage Lines
- Fences
- Sidewalks
- Survey Lines

## Polygon Features

Polygon features represented areas and site features, including:

- Building Footprints
- Landscaped Areas
- Parking Areas
- Survey Parcels
- Survey Site Boundary
